# 具身智能交互实验室

主入口：[index.html](index.html)。页面的四个标签页是“视觉与指令”“扩散生成”“PushT 回放”“评测”。包含中文说明、可拖动目标、参数滑杆、逐步播放、真实物理回放与成功率分析。

## 怎样打开

将本目录中的 `index.html` 下载到电脑，直接双击即可。页面自包含，不依赖网络、外部 JavaScript、模型权重或 GPU。

也可以在项目根目录运行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 <http://localhost:8000/interactive/>。

GitHub 的仓库文件浏览页只显示 HTML 源码，不执行页面。若启用 GitHub Pages，可把仓库根目录或实际包含 `interactive/` 的路径作为发布来源。没有启用 Pages 时，使用下载后双击或本地服务器；本教程不会把未经发布的链接称为可访问网页。

## 与章节的对应关系

| 章节 | 页面操作 | 要理解什么 |
| --- | --- | --- |
| 第一、二章 | 拖起点与目标；查看坐标和二维动作 | 位置与动作语义、观察 → 动作 → 新位置 |
| 第四章 | 改 H / E；第 2 步加入扰动 | 内部预测不执行环境；执行后才重新观察 |
| 第五章 | 在“扩散生成”滑动 k，切正确 / 打乱条件 | 同噪声在条件下迭代更新完整动作块 |
| 第六章 | 在“视觉与指令”同一画面切红 / 蓝指令，移除红色目标 | 视觉、固定指令、自身状态共同决定动作 |
| 第七章 | 在“PushT 回放”选择真实回合，拖时间轴、逐步播放 | 绝对动作目标通过接触物理产生运动与覆盖 |
| 第八章 | 在“评测”改覆盖率阈值和动作预算，点回合检查失败 | 指标定义、有限样本、正式协议与事后分析 |

## 三种证据层次

1. **二维平面是人工规则原理演示。** 从合成 RGB 图像用颜色阈值提取质心，只识别两条固定指令。没有训练 VLA，也没有碰撞或动力学。位置与位移均使用教学平面单位；每轴限幅 0.2。策略每执行 E 步才利用新位置重算计划；页面的重算计数包括初始化的第一次预测。第 2 步的额外 x 位移仅用于观察反馈频率的效果。
2. **扩散标签页是已训练小模型的内部记录。** 数值来自 `results/chapter05/metrics.json` 的 `example`，共 101 个记录（初始噪声 + 100 次更新），正确和打乱条件共享初始噪声。专家参考不是推理输入。页面不重新训练、也不执行动作。
3. **PushT 标签页是实际仿真回放。** 仿真状态、覆盖率与每次动作来自 `results/chapter07/trajectories/`，以官方环境的真实 T 形几何重绘。浏览器不运行 Pymunk 物理计算。模型的输入只有图像和推杆位置；回放中的方块真实姿态是分析数据，不传入策略。

第 0 帧是初始状态，没有动作。之后每帧保存“执行上一动作之后”的状态，所以橙色加号表示产生本帧的动作目标。动作目标是绝对坐标，不是二维位移。

评测标签页使用“预算内历史最高覆盖率 **严格大于** 阈值”的探索判定；官方默认阈值为 0.95。滑动阈值会改变统计定义，不会改善策略。原回合在超过 0.95 时提前结束，因此提高阈值只能检查已保存的片段，不能据此判断继续运行能否达到更高覆盖率。正式成绩以第七、八章事先规定的协议为准。95% 区间采用 Wilson 比例区间；它不等于两个条件差值的显著性检验。

## 重新嵌入已有结果

先实际运行并保存仿真结果，再在项目根目录运行：

```bash
python3 interactive/embed_pusht.py
```

脚本只使用 Python 标准库，读取已有结果并更新 `index.html` 内的 JSON。它检查每一步是否连续、覆盖率与正式成功判定是否一致，不产生实验结果。页面记录嵌入时已完成的回合数、模型版本与评测 JSON 的 SHA-256；正式交付应嵌入全部计划回合。

VLA 页会在当前浏览器保存上次设置；可点“恢复示例参数”重置。保存失败也不影响演示。没有远端数据上传。
